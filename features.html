Built with modern tools for real impact.

GapMap is designed to be fast, accessible, and scalable. Here is the technology stack and resources that power the platform.

System Architecture

GapMap is built as a modular system where the frontend communicates with a backend API and an AI engine to deliver personalised learning experiences.

React Frontend ⇄ Node.js API ⇄ AI / LLM API
PostgreSQL Database Recommendation Engine Learner Profile Store

Why we chose this stack

We chose these technologies because they offer the perfect balance of speed, scalability, and accessibility. The frontend is built with performance in mind, ensuring fast load times even on low-bandwidth connections. The backend is designed to be modular, allowing us to easily integrate AI services in the future. PostgreSQL provides the reliability needed for sensitive learner data, while GitHub enables seamless collaboration. This stack allows us to deliver a high-quality educational tool that can grow with the needs of South African learners.
